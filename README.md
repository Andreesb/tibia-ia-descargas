# Tib.ia: descargas de prueba

Aquí se publican las versiones de prueba de la app de Tib.ia para Android.

**Descargar la última versión:** [tibia-ia.apk](https://github.com/Andreesb/tibia-ia-descargas/releases/latest/download/tibia-ia.apk)

## Cómo instalarla

1. Abre el enlace desde el teléfono y descarga el archivo.
2. Ábrelo. Si Android lo pide, permite instalar apps de esa fuente (el navegador o el gestor de archivos).
3. Si ya tenías una versión de prueba y la instalación falla, desinstálala y vuelve a intentarlo.

Son versiones de prueba: pueden tener fallos.
